# Changelog

Формат раздела: `## [X.Y.Z]` — именно из него workflow берёт текст релиза.

## [1.8.0]

### Автономный exe: никаких внешних модулей на ПК пользователя

- **Node.js встроен в exe.** Скрипт `scripts/bundle-runtime.mjs` (вызывается
  в CI перед publish и доступен локально через `npm run bundle:runtime`)
  копирует `node.exe` в ресурсы хоста. При первом подключении TikTok хост
  разворачивает его в `%LOCALAPPDATA%\YawaChatHub\runtime\node.exe` — ставить
  Node.js на компьютер больше не нужно.
- **TikTok-мост встроен с готовыми модулями.** `tiktok-bridge` упаковывается
  вместе с `node_modules` (tiktok-live-connector ставится строго по
  lock-файлу) в ресурс-архив и распаковывается при первом запуске.
  `npm install` на машине пользователя больше не требуется — чат TikTok
  работает на «чистом» ПК из коробки. Маркер версии архива заставляет
  переизвлечь мост при обновлении приложения.
- **Edge TTS работает без системных медиакодеков.** На редакциях Windows
  N/KN и сборках без Media Feature Pack ACM-декодера MP3 в системе нет, и
  озвучка молча не игралась. Добавлен запасной путь — полностью управляемый
  декодер NLayer, встроенный в exe: сначала пробуем системный кодек, при его
  отсутствии MP3 декодируется управляемым кодом.
- Сообщение об ошибке TikTok уточнено: раньше приложение просило установить
  Node.js, теперь системный Node — только запасной вариант для dev-запуска.

### Чат и интерфейс без служебного мусора

- **Twitch без спама 403-диагностикой.** На каналах, где вход выполнен не
  модератором, все 7 EventSub-подписок отклонялись — и каждая писала в ленту
  служебное «отклонено (403)», размножаясь на каждом переподключении. Теперь
  один дедуплицированный итоговый статус на канал за сессию приложения.
- **Оверлей поверх игры не показывает служебные события.** Диагностика
  (`system`) и tiktok-заходы зрителей больше не пролетают поверх игры —
  остаётся только контент: чат, донаты, подписки, рейды.
- **TikTok без спама «зашёл в эфир»**. События member/join на живом эфире
  шли десятками в секунду и тонули в них полезные сообщения — их обработчик
  в мосте отключён; follow/share/like/gift остались.
- **Подписки озвучиваются.** События подписки (Twitch, VK Play Live, TikTok)
  теперь попадают в очередь озвучки и читаются с именем автора — даже в
  режиме «только донаты».
- **Одна ветка в диспетчере задач.** Встроенный рантайм TikTok извлекается
  под именем `YawaChatHub.exe`: диспетчер задач сворачивает фоновый модуль
  в общую ветку приложения вместо отдельного «Node.js JavaScript Runtime».

### Счётчик зрителей обновляется живо на всех площадках

- **Twitch:** основной источник заменён на публичный GraphQL самого Twitch
  (`user.stream.viewersCount`) — он не зависит от OAuth пользователя и
  проверен прямым запросом на активном канале. Официальный Helix оставлен
  вторым путём, decapi — последним резервом с cache-busting. Опрос раз в 10 с.
- **YouTube:** повторная загрузка watch-HTML удалена — она возвращала
  кэшированные накопленные просмотры ролика, а не текущий онлайн. Теперь
  опрашивается штатный Innertube `/updated_metadata`, разбирается
  `updateViewershipAction → videoViewCountRenderer.originalViewCount` и
  continuation. Интервал берётся из ответа YouTube (обычно 5 с). Работает и
  при выключенном владельцем чате.
- **VK Video Live:** текущий `/v1/blog/{channel}` больше вообще не содержит
  `isOnline/viewers` — это подтверждено реальным ответом API. Статус и
  `count.viewers` теперь читаются из актуального
  `/blog/{channel}/public_video_stream` при подключении и каждые 10 с,
  с запретом кэширования.
- **Kick:** период обновления сокращён с 60 до 10 секунд.
- **TikTok:** к push-событиям `roomUser` добавлена страховка — если push
  молчит дольше 20 секунд, онлайн дочитывается запросом комнаты.

### Лента не выходит за нижнюю рамку

- Устранена гонка между React render, `onScroll` и поздним автоскроллом:
  прокрутка к низу выполняется в `useLayoutEffect` до отображения кадра.
- Добавлен `ResizeObserver` внутреннего содержимого: если эмоут/стикер
  загрузился позже и увеличил высоту строки, лента повторно удерживает низ.
- Внутренний контейнер получил безопасный нижний отступ, а родительские
  flex-контейнеры — `min-h-0` и `overflow-hidden`, поэтому последнее
  сообщение целиком остаётся внутри окна даже при непрерывном потоке.

## [1.7.8]

### Быстрое подключение Twitch и YouTube

- Twitch IRC переведён с часто блокируемого сырого TLS-порта `6697` на
  `wss://irc-ws.chat.twitch.tv:443` — тот же транспорт, который используется
  в рабочем `YawaChat_Hub`. Установлен общий дедлайн подключения 10 секунд.
- Проверка OAuth-логина Twitch теперь идёт параллельно открытию сокета и
  ограничена 3 секундами; проверка зрителей через decapi больше не блокирует
  готовность чата. Статус `connected` выставляется сразу после отправки JOIN.
- Поиск YouTube Live больше не выполняет последовательно три запроса по
  20 секунд. Страницы `/live`, `/streams` и Innertube search проверяются
  параллельно с общим дедлайном 8 секунд.
- YouTube-чат открывается отдельно через popout URL; если HTML не содержит
  continuation, выполняется fallback `youtubei/v1/next`. Поддерживаются
  timed/invalidation/reload continuation.
- Офлайн-канал YouTube получает явный статус `offline` максимум через 8 секунд,
  а не остаётся в вечном `connecting`; повторная проверка выполняется через
  45 секунд вместо двух минут.
- Устранена утечка фоновых задач обновления зрителей YouTube после reconnect.

### TikTok Live — один рабочий коннектор вместо четырёх

- **Удалены все самописные пути подключения к TikTok**: скрытое окно WebView2
  (`TikTokLive.cs`), собственный webcast-WebSocket (`TikTokLiveWs.cs`),
  ручной разбор protobuf (`TikTokProto`) и поллинг `webcast/im/fetch`.
  Они находили комнату (канал показывался «в эфире»), но push-сокет молчал —
  сообщения не приходили.
- Оставлен **единственный проверенный путь** — модуль `tiktok-live-connector`,
  тот же, что работает в Electron-сборке `YawaChat_Hub`. Логика перенесена
  один в один (`tiktok-bridge/bridge.js`):
  - комната ищется заранее через `api-live/user/room`, авторитетен
    `data.user.roomId`, `status=4` — канал не в эфире;
  - при найденном `roomId` отключается `fetchRoomInfoOnConnect`;
  - мягкий TLS-агент и для HTTP (`got`), и для WebSocket (`ws`) — иначе при
    антивирусе/TLS-инспекции сокет не поднимается;
  - чат принимается **двумя путями** — `decodedData` и `chat`, дубли отсекает
    `WeakSet` (на части сборок `WebcastChatMessage` не сопоставляется с
    событием, хотя protobuf уже декодирован);
  - «Failed to retrieve Room ID» трактуется как «не в эфире»: повтор раз в
    60 с вместо 20 с;
  - зрители — из события `roomUser`, без лишних запросов.
- Подарки, подписки, репосты, входы и лайки приходят в ленту; эмодзи-смайлы
  собираются по `placeInComment` в токены `[[e|URL|имя]]`.
- Мост встроен в exe: при первом подключении разворачивается в
  `%LOCALAPPDATA%\YawaChatHub\tiktok-bridge` и один раз ставит зависимость.
- Поле cookie для TikTok больше не нужно — достаточно `@username`.

## [1.2.0]

### Electron → WebView2

- Десктоп-оболочка перенесена с Electron на **WebView2** (.NET 8, WinForms):
  окно без системной рамки, ресайз за края, перетаскивание за шапку,
  запуск рендерера из встроенной Vite-сборки.
- Мост `chrome.webview.postMessage` ↔ рендерер заменил Electron IPC:
  те же методы — `settings.*`, `window.*`, `tts.*`, `overlay.*`,
  `widget.info`, `hotkeys.apply`, `clipboard.set`, `shell.openExternal`.
- Настройки хранятся в `%LOCALAPPDATA%\YawaChatHub\settings.json` (как раньше).
- Озвучка через **SAPI** (`SAPI.SpVoice`) — миграция модуля tts из Electron.
- Глобальные хоткеи через Win32 `RegisterHotKey` — работают поверх игры.
- Игровой оверлей — второе окно `CoreWebView2` поверх всех окон,
  «клик-сквозь» (`WS_EX_TRANSPARENT`), живой рендерер `#/overlay`.
- Сервер OBS-виджета на `127.0.0.1:8085` (`HttpListener` + SSE `/widget/events`).
- Трей с меню «Показать / Выход», сворачивание по «крестику» (настраивается).

### Интерфейс (1:1 от оригинала + правки по обратной связи)

- **Каналы**: модалка добавления с выбором площадки, новые карточки
  (цветная полоса, статус, зрители), починено сворачивание/разворачивание
  панели — явная кнопка-стрелка.
- **Навигация**: в рейле только «Лента» и «Чат-бот»; все настройки
  собраны под шестерёнкой (11 вкладок с поиском).
- **Авторизация бота**: крупные карточки «Войти» для Twitch и VK Play Live
  в разделе «Чат-бот» + компактный блок в панели каналов, общее состояние.
- **Переключатели**: убраны декоративные — каждый контрол сохраняется
  и влияет на поведение (лимит ленты, подсветка упоминаний, скрытие
  удалённых, сигнал перед донатом, порт виджета и др.).
- **Лента**: автоскролл привязан к id последнего сообщения — работает
  и после достижения лимита ленты.
- **Стикеры**: эмоуты по площадкам (Twitch CDN + общий набор), крупные
  стикер-сообщения, фолбэк на код при недоступной картинке.
