# Правила работы с репозиторием

Требования владельца проекта. Соблюдать при каждом изменении — без
напоминаний и без отдельного запроса.

## 1. README.md — только про новые возможности

Файл `README.md` — витрина проекта для обычного пользователя.

**Обновлять обязательно, когда:**

- добавлена новая площадка или сервис донатов;
- появилась новая заметная функция приложения.

**Не трогать во всех остальных случаях:** исправления ошибок, ускорения,
внутренние переделки и мелкие правки интерфейса README не меняют.

**Никогда не добавлять** в README разделы о сборке, компиляции, разработке,
зависимостях разработчика, подписи кода и внутреннем устройстве. Там только:
описание приложения, список возможностей, установка, ссылки на скачивание,
донат, телеграм-группу и трансляции автора.

## 2. Список изменений — только для пользователя

Файл `CHANGELOG.md` обновляется при каждом заметном изменении приложения и
пишется на языке пользователя, а не разработчика.

**Формат**

- Одна версия — один раздел `## [X.Y.Z]`, из него собирается текст релиза.
- **Каждый релиз хранит только свои изменения.** Нельзя складывать всю работу
  в один раздел: новая порция правок — новая версия сверху.
- Номер верхнего раздела обязан совпадать с файлом `VERSION` — это версия
  следующего релиза. При добавлении нового раздела `VERSION` поднимается.
- Внутри версии — смысловые разделы с заголовком `###`.
- Пункт — одна мысль в 1–2 строки: что было не так и что теперь работает.
- Старые разделы не переписываются и не объединяются.

**Запрещено упоминать**

- имена файлов, классов, функций, методов и переменных;
- названия библиотек, пакетов, API, эндпоинтов и протоколов;
- пути в коде, номера портов, ключи реестра, фрагменты кода;
- детали сборки, CI, публикации и внутренней архитектуры.

**Правильно:** «Озвучка заработала на компьютерах, где раньше молчала».
**Неправильно:** «Добавлен резервный декодер NLayer в `EdgeTts.cs`».

## 3. Общее

- Технические подробности остаются в комментариях к коду, а не в документации
  для пользователя.
- Любые новые пользовательские ссылки (донат, соцсети, сообщество) берутся из
  раздела «Поддержи автора» в приложении и должны совпадать с ним.
